# Finite Element Analysis & Terrain Integration of a Three-Story RC Landmark

Civil engineering capstone project integrating reinforced-concrete structural analysis, foundation design, terrain reconstruction, and site modeling.

## Project Overview

The project developed a conceptual three-story reinforced-concrete building integrated into the National Chung Hsing University lakeside environment.

The project included:
- RC structural and foundation design
- UAV imagery and RTK control-point surveying
- 3D site reconstruction using Metashape
- Terrain and architectural integration in SketchUp
- Structural analysis using MIDAS Civil
- Shear-force and bending-moment evaluation
- Displacement analysis
- Beam and column member checks

## Structural & Foundation Parameters

- Plan size: 15 m × 15 m
- Story heights: 4.0 / 3.5 / 3.0 m
- Columns: 50 × 50 cm, 14-D36, D13@50 cm
- Beams: 50 × 60 cm, 4-D25, D10@25 cm
- Concrete compressive strength: 280 kgf/cm²
- Foundation: 9 isolated footings
- Footing depth: 2.0 m
- Footing size: 0.6 × 0.6 m
